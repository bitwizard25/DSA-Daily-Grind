# C++ interview foundations

Use C++17 or later. Practise writing these from memory, then trace a small example.

- [ ] Choose types for the largest intermediate value. Use `1LL * a * b` when int multiplication could overflow.
- [ ] Write conditions with `&&`, `||` and `!`. Group blocks with braces.
- [ ] Use `vector`, indexed access, `push_back`, `back`, `pop_back` and `empty`.
- [ ] Choose value loops for reading and reference loops for changing elements.
- [ ] Pass large read-only inputs as `const vector<int>&`; explain when mutation is intended.
- [ ] Check empty input, one element, duplicate values and index boundaries.
- [ ] Use `unordered_map` for key-value lookup and `unordered_set` for membership. Explain average O(1), worst O(n).
- [ ] Use `stack` for last-in-first-out and `queue` for first-in-first-out. Read before popping.
- [ ] Choose a max-heap or min-heap; explain O(log n) insertion/removal.
- [ ] Sort before binary search. Check for `end()` before dereferencing a search result.

The C++ lesson checks show expected output from bundled examples. They do not compile your code. The whiteboard remains a plain interview practice pad; a runnable editor is a separate planned feature.

Changing Python/C++ in Learn changes the foundations track and the language for new coding sessions in the current preparation mode. Your saved Python and C++ code pads and lesson progress are kept separately. Google and General mode remember their own language choice.
